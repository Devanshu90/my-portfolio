## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Devanshu90/my-portfolio.git
```

Navigate to the project directory:

```bash
cd my-portfolio/frontend
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build the project:

```bash
npm run build
```
